Typography

A complete reference for titles, paragraphs, font sizes, weights, spacing, and text treatments. Every specimen includes the Tailwind classes needed to reproduce it.

Download UI theme design.md

Usage & approach

Inter is the brand UI font. Normal paragraphs use text-base: 1rem, or 16px with the default 16px browser root. Leave the root size responsive to browser preferences. Choose heading elements by document hierarchy, then choose their visual size independently. Use one page h1 and do not skip heading levels. The 400, 500, 600, and 700 font files are loaded; the other Tailwind weight mappings are documented as reference-only. Italic is a browser-synthesized treatment unless a matching italic font file is supplied.

Specifications

Default body
font-sans text-base font-normal leading-7: 1rem type, 1.75rem line height.
Page title
text-4xl sm:text-5xl font-semibold tracking-tight leading-tight: 2.25rem → 3rem.
Section title
text-2xl sm:text-3xl font-semibold tracking-tight: 1.5rem → 1.875rem.
Supporting UI
text-sm (0.875rem) for labels; text-xs (0.75rem) for captions. These supplement 1rem paragraphs.
Loaded weights
font-normal 400, font-medium 500, font-semibold 600, font-bold 700. Other weights need matching font assets.
Measure and spacing
max-w-prose for reading; leading-7 for body; tracking-tight for larger headings; tracking-normal for paragraphs.
Text colors
Primary: text-[#183d2c] dark:text-[#f4f5f2]. Supporting: text-[#333] dark:text-[#c4c7c5].
Data and code
tabular-nums for aligned figures; font-mono for code and references. Match the selected font to the content.

Line height

Named leading utilities are unitless multipliers. leading-7 is spacing-based: 1.75rem (28px at the default root), making it the normal paragraph setting. leading-none (1) is suitable only for short display text, not body paragraphs.

Alignment, wrapping & truncation

Keep reading paragraphs left-aligned. Use centered text for short introductions and right alignment for numbers. text-balance improves heading wraps, text-pretty reduces awkward body wraps, and truncation should be limited to secondary content with a way to inspect the full value.
