Colors

Logo greens anchor the brand. Warm neutrals, sage surfaces, and a clear text hierarchy give the interface room to breathe.

Download UI theme design.md

Usage & approach

Insurance green (#006838) is the primary action color in both themes, paired with white text. Leaf green remains a brand accent. Dark mode uses charcoal and grey surfaces, with soft white links and supporting text for readability.

Color palette

Every swatch includes its exact Tailwind utility. Choose text and surface pairings deliberately; a listed text utility is a reference, not approval for every background.
